# 📰 News24/7

**News24/7** is a simple, responsive web application that allows users to search for the latest news articles from around the world using the [NewsAPI](https://newsapi.org/). The app dynamically fetches and displays articles based on the user's search query. Built with HTML, CSS, and JavaScript, it provides a clean and interactive way to stay updated on current events.

---

## 🛠️ Features

- 🔍 Real-time news search
- 🗂 Responsive layout for all screen sizes
- 🖼 Article preview with image, description, source, and link
- 📅 Displays the current date and time
- 🎨 Simple and clean UI design with soft colors

---

## 🚀 Technologies Used

- **HTML5** – Structure of the web page
- **CSS3** – Styling and layout
- **JavaScript (ES6)** – Logic and API calls
- **NewsAPI** – Source of news content
